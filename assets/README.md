# Cached sound assets

`sfx/` (24 sounds) and `music/` (2 loops) were generated once with ElevenLabs and cached so a render never calls the API.
Whether generated audio may be redistributed depends on the plan it was made under, so **the provenance and the right to redistribute are
unconfirmed.** Before this repo is made public, either confirm the terms, or replace the files with CC0 sounds (Mixkit, Freesound CC0) or your own,
keeping the same file names. Nothing else in the repo depends on the sounds themselves.
